Euler-Lotka equation

Births at time t are equal to the sum over age groups (x) number of females born x years ago, times their survival to age x (lx) times their fecundity at age x (mx).

\[ B_t= \sum_{x=0}^{x_{max}} B_{t-x} l_x m_x \]

And population is growing (or declining) at rate \(\lambda=e^{r_m}\). So births are

\[ B_t=B_0\lambda^t \] Substituting

\[ B_0\lambda^t = \sum_{x=0}^{x_{max}} B_0\lambda^{t-x}l_x m_x \]

\(B_0 \lambda^t\) cancels out, leaving

\[ 1 = \sum_{x=0}^{x_{max}} \lambda^{-x} l_x m_x \]

Or equivalently

\[ 1 = \sum_{x=0}^{x_{max}} e^{-r_m x} l_x m_x \] Solve numerically for \(r_m\)

EulerEquation<-function(rm,data) {
  (sum(exp(-rm*data$x)*data$lx*data$mx)-1)^2
}
rvals<-data.frame(r=seq(-0.1,0.2,by=0.01))
for(i in 1:length(rvals$r)) {
 rvals$Euler[i]<-EulerEquation(rvals$r[i],data=list(x=squirrel$x,
                        lx=squirrel$lx,
                        mx=squirrel$mx))
}
ggplot(rvals,aes(x=r,y=Euler))+geom_line()

\(r_m\) can also be approximated by just assuming each female produces \(R_0\) offspring at age %T_c% so that

\[r_c=log(R_0)/T_c\] which is, for the squirrels

elasticityFunc<-function(A) {
 w<-Re(eigen(A)$vectors)[,1]
 v<-left_eigen(A)[,1]
 w<-w/sum(w)
 v<-v/v[1]
 lambda<-Re(eigen(A)$values)[1]
 sensitivity<-outer(v,w)/sum(v*w)
 elasticity<-(A/lambda)*sensitivity
 elasticity
}

Monte Carlo estimation of uncertainty

getLeslie<-function(lx,mx) {
  Pvals<-lx[2:6]/lx[1:5]
  Fvals<-mx[2:6]*Pvals
  Leslie<-matrix(0,5,5)
  Leslie[1,]<-Fvals
  for(i in 1:4) Leslie[i+1,i]<-Pvals[i]
  Leslie
}
squirrel.lx.cv<-0.02
squirrel.mx.cv<-0.05
nsim<-100000
lambdaSims<-NULL
for(sim in 1:nsim) {
  lx<-c(1,rnorm(5,squirrel$lx[2:6],squirrel.lx.cv*squirrel$lx[2:6]))
  mx<-rnorm(6,squirrel$mx,squirrel.mx.cv*squirrel$mx)
  A<-getLeslie(lx,mx)
  lambdaSims[sim]<-Re(eigen(A)$values[1])
}
summary(lambdaSims)
